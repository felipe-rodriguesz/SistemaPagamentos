# SistemaPagamentos

Projeto acadêmico desenvolvido na disciplina de **Programação Orientada a Objetos (POO)**. Implementado em **Java** com interface gráfica em **Java Swing**, o projeto tem como objetivo aplicar conceitos de orientação a objetos na construção de um protótipo de sistema para aluguel de itens.

O protótipo reúne operações de **aluguel, reservas, pagamentos e relatórios**, com os dados mantidos em memória durante a execução.

Os pagamentos são **simulados localmente**. Este projeto não é um gateway de pagamentos nem um sistema financeiro real, e não processa transações financeiras.
